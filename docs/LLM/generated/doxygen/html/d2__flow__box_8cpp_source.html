6 {
7 // Division into virtual groups
8 // Each sequence of elements with the same direction of alignment (vertical/horizontal)
9 // belongs to the same virtual group.
10 // The virtual group's alignment is the alignment of the next group
11 // If we have a block with alignment A and the last element has alignment A and B then we introduce a break.
12 // We proceed as usual by constructing a new block, but we only reset the offset corresponding to the previous
13 // block's alignment
14 // Examples:
15 // Child 1,2 - horizontal
16 // Child 3 - vertical
17 // Child 4 - horizontal
18 // Virtual Groups: {{{ 1H, 2H }V, 3V }H 4H }
19 // Horizontal group
20 // A - X
21 // B - X
22 // Break / horizontal group (carries from previous group)
23 // C - X,Y
24 // D - X
25 // Result
26 // AB
27 // CD
28 //
29 // Size pooling
30 // Each virtual group which contains an element with a relative size is marked as volatile.
31 // If the relative size is aligned with it's positioning, the group receives a 'pool' of size
32 // which it will allocate equally between it's elements (that have relative sizes on this axis).
33 // Elements with absolute dimensions will substract their sizes from the pool.
34 // If the relative size is not aligned with it's positioning, the entire group will be subject to this procedure
35 // with respect to the rest of the groups on this axis.
36 // Examples:
37 // Q - X
38 // A - XW
39 // B - XW
40 // C - XYW
41 // D - XW
42 // Layout:
43 // Q(Q_width) A((width - Q_width) / 2) B((width - Q_width) / 2)
44 // C(width / 2) C(width / 2)
45 //
46 // Q - Y
47 // A - XYWH
48 // B - XWH
49 // C - XYWH
50 // D - XWH
51 // Layout:
52 // Q(*, Q_height)
53 // A(*, (height - Q_height) / 2) B(*, (height - Q_height) / 2)
54 // C(*, (height - Q_height) / 2) D(*, (height - Q_height) / 2)
